# 🧰 极客运维工具箱 (Server Toolbox)

> 面向 Linux 运维与开发者的微型瑞士军刀。

## 💡 功能亮点
1. **常用 Linux 命令一键速拷**：包含 Docker、Systemd、网络端口监听与磁盘排查命令。
2. **随手记事便签**：临时保存密钥、排错 IP 或脚本片段，自动在本地 localStorage 中静默持久化。
3. **网络连通性探测**：网页级发包延迟测试，迅速判断目标 API 是否通畅。
4. **Unix 时间戳换算**：实时显示当前秒级与毫秒级时间戳。

## 📦 文件结构
- `saki-plugin.json`: 插件清单
- `index.html`: 单文件微应用，纯原生 HTML/JS，零依赖
- `preview.svg`: 预览图
