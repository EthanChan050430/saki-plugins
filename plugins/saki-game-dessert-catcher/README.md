# 🍰 Saki 的甜点大作战 (Dessert Catcher)

> 纯原生 HTML5 Canvas + Web Audio API 街机治愈小游戏。
> 随时随地，在 Saki Panel 摸鱼打一把！

## 🎮 玩法介绍
1. **移动**：按键盘 **← / →**、**A / D**，或者直接使用鼠标 / 手指在屏幕上滑动。
2. **得分**：接住掉落的马卡龙 (+10)、草莓蛋糕 (+25) 和金星 (+50)。
3. **避让**：千万小心红辣椒！接错会扣除 1 颗心并打断连击倍数。
4. **街机音效**：内置 8-bit 复古合成音效，无需下载额外音频文件。

## 📦 文件结构
- `saki-plugin.json`: 插件清单
- `index.html`: 单文件完整游戏实现
- `preview.svg`: 封面图
